# P0 데이터 안전장치 1차 적용

2026-09-27 / 로컬 적용, 운영 배포·원본 재수집은 하지 않음.

## 구현

- `audit_market_data.py`: 고정 버전 exchange_calendars의 XKRX/XNYS 월말 거래일과
  실제 관측일을 대조한다. 당월·미래 월, 불일치 월, 잘못된 전월 기준가격을 사용한 월은 제외한다.
- 원본 `monthly_returns`는 보존한다. 추가 메타데이터로 제외 사유와 최신 연속 사용 구간을 기록한다.
  누락 월을 건너뛰어 시계열을 이어 붙이지 않는다. 최근 구간이 너무 짧으면 분석을 거절한다.
- 수집기는 전월 기준가격 관측일을 새 행에 기록한다. 정상 0% 수익률을 스테일로 오인해 삭제하지 않는다.
- 데이터 계약 검증에서 감사를 재계산하고 카탈로그/종목 파일 일치를 확인한다.
  평일 갱신 workflow에 감사 단계를 넣어 누락된 감사나 잘못된 메타데이터의 게시를 차단한다.
- 본편·v1 공유·전략 랜딩·사전 계산 샘플은 공통 로더를 사용한다.
  USD S&P500 가격지수는 검증된 원화 환산이 없어 계산을 거절한다.
  국내 상장 KRW 해외 ETF에는 별도 환율을 중복 적용하지 않는다.
- 결과의 접이식 상세에 기간 제한·최신 완료월 대비 지연·분배금 검증 범위를 표시한다.
  새 v2 공유에는 해당 설명도 저장한다. 기존 v2 수치는 재계산하지 않는다.

## 현재 로컬 데이터에 미친 영향

150개 자산 감사 결과 106개 자산에서 총 246개 월 관측치가 제외 대상으로 판정됐다.
월말 불일치의 다음 월도 기준가격 불일치로 포함한다. 이 숫자는 공급자 가격 오류의 확정 건수가
아니라 거래일 달력 기반 사용 제외 건수다. 최신 연속 구간 밖의 정상 과거 월도 분석에서는 제외된다.

예: KOSPI200의 2026-07 관측일은 7월 16일이므로 7월을 사용하지 않는다.
KODEX 200의 2023-07 관측일은 7월 28일이며 7월 및 8월 기준가격을 제외한다.
기본 한국 60/40 샘플은 2023-09~2026-07, 35개월로 줄었다. 이전 장기 결과와 직접 비교하면 안 된다.
원본 기준일 2026-08-05는 변경하지 않았다. 감사일을 시세 기준일로 표시하지 않는다.

## 검증 및 남은 과제

- 최종 검증: Node 21 + Python 20 = 41개 테스트 통과, 150개 데이터 계약 검증 통과.
  Git HEAD 대비 150개 원본 월 수익률 배열 변경 0건.
  브라우저에서 본편 35개월 결과·USD 선택 거절·v1 공유·전략 랜딩·단일 파일판을 확인했다.
  로컬 미리보기는 기존 포트의 브라우저 캐시 영향을 피하여 8124에서 검증했다.
- 동결 골든 산식/입력은 유지했다. 품질 필터의 영향과 원본 수익률 개정 감시는 별도 테스트한다.
- 데이터 계약, 월말/휴장일/기준가격, KRW 연속성, USD 차단, 공유 v1/v2 호환을 테스트한다.
- 달력 대조는 거래소 공식 가격·분배금 원장 검증이 아니다. 기존 첫 수익률의 기준가격 관측일은
  원본에 없으므로 미확인으로 표시한다. 가격·총수익 정확성을 보증하지 않는다.
- 다음 P0: 누락 일별 원본 복구 → 대표 ETF 분배금/분할 원장 독립 대사와 이용권한 확인
  → 공유/랜딩/몬테카를로 계산 core 통일 및 독립 계산 교차 검증.
- 실제 Actions 성공·최신 데이터 복구·Vercel 배포 확인은 별도다. 이번 변경만으로 운영 정상화라고 하지 않는다.
