# 백테스트K — Research Workspace

2026-09-27. 정적 HTML/CSS/Canvas 구조를 유지한 전체 디자인 리뉴얼.

## 방향과 참고

- inspo MCP의 `search_screens`와 `get_screen`으로 Public, Wise, Coinbase를 확인했다.
- Public(https://public.com)의 명확한 위계와 여백, Wise(https://wise.com)의 입력 중심 구성,
  Coinbase(https://coinbase.com)의 선명한 데이터 표현을 참고했다. 자산·이미지·폰트는 복제하지 않았다.
- UI/UX Pro Max의 design-system 검색은 두 차례 모두 홍보용 Enterprise Gateway 패턴을
  반환해 채택하지 않았다. 접근성·반응형·차트 가독성의 일반 기준을 사용해 분석 도구에 맞게 설계했다.

## 디자인 토큰

- 기본 테마: 밝은 미네랄 배경 `#f5f6f2`, 흰 카드, 딥그린 `#246043`.
- 본문 `#1d3025`, 보조 텍스트 `#5a6b60`, 경계 `#e1e6dd`.
- 다크 모드: 포레스트 배경 `#101916`, 카드 `#19251f`, 민트그린 `#9cdbb2`.
- 한글 시스템 글꼴 사용. 외부 폰트·UI 라이브러리·서비스 의존성 추가 없음.
- 숫자에는 tabular-nums, 주요 성과 숫자는 20–28px. 카드 radius 16px.
- 설정 350px / 분석 결과 가변 폭. 900px 이하 단일 열, 620px 이하 모바일 조정.

## 컴포넌트 규칙

- 네비게이션·모드·분석 선택의 활성 상태를 색상과 배경/밑줄 및 aria-pressed로 전달.
- 성과 첫 카드만 딥그린 강조. 차트·위험 표는 중립 배경으로 데이터가 주인공이 되게 한다.
- 입력 라벨·₩·세 자리 콤마, 데이터/가격지수 경고와 샘플 표시를 유지한다.
- 모바일 주요 터치 타겟 44px, 표는 내부 가로 스크롤, 키보드 포커스 및 본문 건너뛰기 제공.
- prefers-reduced-motion을 존중한다. 장식 이모지 대신 SVG와 텍스트를 사용한다.
- 기존에 저장한 사용자의 테마는 유지한다.

## 변경 경계

계산식, 데이터, 공유 v1/v2 코덱, 스냅숏 불변성, 이벤트 종류는 변경하지 않는다.
포트폴리오 페이지는 생성기를 수정한 뒤 재생성하고, 단일 HTML도 소스로부터 재생성한다.

## 검증 기록

- `npm test`: Node 12개 + Python 16개 통과. 최초 샌드박스의 자식 프로세스
  생성 제한(EPERM)은 승인된 제한 외 테스트 실행으로 해소했다.
- `validate_market_data.py data`: 150종목 데이터 계약 통과. 데이터 갱신 작업은 하지 않았다.
- app/engine/share/portfolio JavaScript 구문 검사 통과.
- 브라우저: 1440px 데스크톱, 375px 모바일, 812×375 가로 화면 확인.
- 모바일 4개 메뉴에서 문서 가로 넘침 없음, 성과 숫자 말줄임 없음.
- 백테스트·몬테카를로 실행, 상세 입력 전환, 티커 자동완성, 분석 선택, 테마 전환 확인.
- 한국 60/40 소개 페이지와 v1 공유 페이지의 데이터 렌더링 확인.
- 주요 텍스트/카드 배경 대비: 라이트 4.92–13.98:1, 다크 6.54–14.21:1.
  전체 페이지의 WCAG 인증을 의미하지 않는다. 스크린리더 실기기 검증은 수행하지 않았다.
- 로컬 캡처는 Git 제외 경로 `artifacts/design-review/`에 보관한다.
- Vercel 운영 배포는 수행하지 않았다.
