# PC의 기존 API를 이용한 복구

실행일: 2026-09-27. 로컬 데이터 반영, 커밋·운영 배포 없음.
검증: Node 21개 + Python 27개, 총 48개 통과. 동결 골든 입력·산식은 변경하지 않았다.

## 접근 범위

기존 한국투자증권API 프로젝트에서 KIS·KRX 설정을 발견해 각 공식 시세 서버에서만 사용했다.
인증키·토큰 값은 출력하거나 백테스트 저장소에 저장하지 않았다. 기존 설정 및 토큰 캐시는
변경하지 않았고, 주문·잔고·메시지·예약 보고서 작업은 수행하지 않았다.
기존 수급 SQLite는 읽기 전용으로 테이블 목록만 확인했다. ETF 달력·ETF Finder·제안서 폴더의
파일명 탐색에서는 이번 복구에 사용할 완전한 분배락·분할 원장을 찾지 못했다.
이는 PC 전체에 원장이 없다는 뜻은 아니다.

## 실제 복구: KOSPI200

| 월말 | KRX ETF 응답의 코스피200 기초지수 | 대조 |
|---|---:|---|
| 2013-02-28 | 268.01 | KODEX 200·TIGER 200 참조값 일치 |
| 2013-03-29 | 263.39 | 동일 |
| 2013-04-30 | 255.72 | 동일 |
| 2026-06-30 | 1370.73 | 위 두 값 + KIS 지수 조회 일치 |
| 2026-07-31 | 1046.81 | 동일 |
| 2026-08-31 | 1071.85 | 동일 |

KRX 지수 전용 API는 HTTP 401이었지만 허용된 ETF API에서 `IDX_IND_NM=코스피 200`인
`OBJ_STKPRC_IDX`를 확인했다. 두 ETF의 종가를 지수로 사용한 것이 아니다.
최근 값은 KIS 지수 코드 2001, 응답 명칭 KOSPI200과도 대조했다. 권한은 변경하지 않았다.

전월·당월을 같은 KRX 원천으로 나누어 2013-03, 2013-04, 2026-07을 정정하고
2026-08을 추가했다. 이전 행은 로컬 `applied-revisions.json`에 보관했다.
사용 가능한 연속 구간은 **1998-12~2026-08**로 복구됐다.
1990년대 토요일 관측 누락은 여전히 제외한다. 전체 역사 검증 상태는 provisional을 유지한다.

`data/repairs/kospi200-month-ends.json`에 날짜·가격·출처·응답 해시를 기록했다.
`scripts/restore_index_months.py`가 이 계약을 재적용하여 다음 정상 데이터 수집 후에도 복구를 유지한다.
이는 기존 수집기 자체가 실패할 경우의 우회나 실제 Actions 성공을 의미하지 않는다.

## ETF: 원시값 확보, 총수익 복구 보류

2023-07-31 KRX 원시 종가: KODEX 200 34,635원, KODEX 국고채3년 57,650원.
KIS 예탁원 배당일정은 KODEX 200의 지급기준일 2023-07-31, 1주당 75원,
지급일 2023-08-02를 반환했다. KODEX 국고채3년은 해당 조회 기간 응답이 비어 있었다.
빈 응답을 무분배 증거로 취급하지 않았다. 지급기준일은 분배락일이 아니다.

원시 종가를 기존 수정종가에 섞으면 총수익이 왜곡될 수 있으므로 ETF 월 수익률은 바꾸지 않았다.
따라서 기본 한국 60/40 분석은 여전히 2023-09~2026-07이다.
카탈로그의 최신 기준일 2026-08-31은 복구된 지수 기준이며 모든 ETF가 8월까지 갱신됐다는 뜻이 아니다.

## 재현 및 보안

- `scripts/recover_local_api.py`: 기존 .env 경로를 인자로 받아 KRX 공개 시세만 조회
- `scripts/probe_local_kis.py`: KIS 지수·예탁원 배당일정만 조회, 토큰을 출력·저장하지 않음
- `scripts/restore_index_months.py --write`: 검증된 가격지수 복구 적용, ETF 총수익은 거절
- `artifacts/local-api-recovery/`: 로컬 근거. Git 제외이며 외부 업로드 없음

GitHub Actions에 PC의 키를 복사하지 않았다. 기존 키의 서비스 이용·재배포 조건이
공개 서비스에 적합한지는 별도 확인이 필요하다.
